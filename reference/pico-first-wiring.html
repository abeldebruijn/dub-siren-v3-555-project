Power-off rule

Before moving a wire Unplug USB. Inspect the whole path. Reconnect USB only after the circuit is complete.

Names on the board

  • GP15: general-purpose pin 15. Our first controllable output.
  • GND: ground, the circuit’s 0 V return path.
  • 3V3: regulated 3.3 V. Used later for potentiometers.
  • VBUS: USB’s 5 V. Do not use it for these beginner control circuits.
  • ADC: a pin that can measure a variable voltage. Used later for potentiometers.

LED polarity

positive side → long leg
anode + LED short leg
cathode − → GND

The flat edge on many LED bodies also marks the cathode. If leg lengths disagree with the flat edge, stop and verify the specific LED.

Resistor rule

A normal resistor has no polarity. It may face either direction. An LED always needs a series resistor.

From the owned values, use 1 kΩ (brown·black·red·gold) with a red LED. The simple estimate is about 1.3 mA: modest and normally visible. Do not confuse it with 100 Ω (brown·black·brown·gold). See Reading resistors for the colour tool and calculation.

If nothing happens

  1. Unplug USB.
  2. Rotate the LED 180°; do not rotate the resistor.
  3. Confirm each LED leg is in a different breadboard row.
  4. Trace GP15 → resistor → LED long leg → LED short leg → GND.
  5. Confirm picozero.py exists on the Pico and your script uses LED(15).
Print this page and keep it beside the breadboard. When uncertain, stop and ask your teaching agent before reconnecting USB.
