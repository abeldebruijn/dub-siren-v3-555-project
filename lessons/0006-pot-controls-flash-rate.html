Dub Siren V3 · lesson 0006

Make a visible LFO

Hold Trigger and turn the potentiometer. The LED repeats slowly or quickly like the modulation-rate indicator in your dub siren.

15–20 min · no wiring changes

← Lesson 5 Map rate Code Test Lesson 7 ->
Today’s win The potentiometer controls a repeating event instead of brightness. This is your first low-frequency oscillator, or LFO.

1. Keep the complete circuit

Keep the green LED on GP15 with its 1 kΩ resistor, button on GP14, and potentiometer wiper on GP26. No wires move.

Button gates repeating flash while Pot sets rate

2. Turn 0…1 into milliseconds

The loop needs a time interval. This line maps the pot to 500…50 milliseconds:

interval = int(500 - pot.value * 450)
  • At pot.value = 0.0: interval is 500 ms.
  • At pot.value = 0.5: interval is 275 ms.
  • At pot.value = 1.0: interval is 50 ms.
Predict

Why does a smaller interval make the LED flash faster? Predict which end of the knob will be fastest.

3. Run the LFO

Run this main.py:

from picozero import Button, LED, Pot
from time import sleep, ticks_diff, ticks_ms

led = LED(15)
button = Button(14)
pot = Pot(26)

last_change = ticks_ms()

while True:
    interval = int(500 - pot.value * 450)

    if button.is_pressed:
        now = ticks_ms()
        if ticks_diff(now, last_change) >= interval:
            led.toggle()
            last_change = now
    else:
        led.off()
        last_change = ticks_ms()

    sleep(0.01)

ticks_ms() reads the Pico’s millisecond clock. ticks_diff() asks how much time passed. The loop keeps checking the button every 10 ms, so release can turn the LED off quickly even at the slowest rate.

4. Play and test

  1. Release button: LED remains off at every knob position.
  2. Hold button with knob fully slow: count five flashes.
  3. Keep holding and turn toward fast: rate changes immediately.
  4. Release during a slow flash: LED turns off without waiting for the interval.
The direction feels backwards

Change the mapping to interval = int(50 + pot.value * 450). This changes software direction without moving the pot wires.

The LED appears dim at the fastest end

At high speed, separate flashes merge visually. That is normal. Slow it down and confirm distinct on/off changes return.

5. Translate it to the synthesizer

The LED shows the LFO’s timing. Later the same repeating value will change pitch or another sound parameter. The pot becomes Mod Rate; the button remains Trigger.

Done means

  • The LED flashes only while Trigger is held.
  • The pot moves smoothly from slow to fast.
  • Release turns the LED off promptly.
  • You can explain why a smaller interval means a faster rate.
