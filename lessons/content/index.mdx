# Build a Pico Dub Siren

Learn electronics by building a playable siren: LEDs first, then buttons, knobs, multiplexers, and finally a small synth control panel.

No prior Pico or breadboard experience is assumed. Each lesson adds one useful control, and your progress stays in this browser.
