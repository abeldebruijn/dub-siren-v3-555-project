Blink a real LED

Your first siren subsystem: the Pico switches a physical LED on and off. Later, the same LED will pulse at the modulation rate.

15–25 min · no solder · beginner

Parts Install Wire Code Test Wiring reference Reading resistors
Today’s win The external LED blinks once per second. You then predict and create a faster rhythm.

1. Gather only these parts

  • BrainRaspberry Pi Pico 2 with headers
  • WorkspaceFull-size breadboard
  • LightOne 5 mm LED — use red, not white
  • ProtectionOne 1 kΩ resistor
    brown·black·red·gold — how to read it
  • ConnectionsTwo male-to-male jumper wires
  • Power + dataMicro-USB data cable and Mac

Every item above is marked bought or starter-pack supplied in your shopping list.

Non-negotiable safety habit Build or change wiring only while USB is unplugged. Never connect the LED without a series resistor. Use GP15 and GND—not VBUS.

2. Give the Pico its language

We use MicroPython with your preferred picozero package.

  1. Install the official Pico 2 MicroPython firmware using your editor or the Raspberry Pi instructions.
  2. Follow picozero’s installation guide so picozero.py exists on the Pico.
  3. Run from picozero import LED in the MicroPython shell. No error means the library is ready.

Checkpoint: stop here until the import succeeds.

3. Build one complete path

Unplug USB. Place the Pico across the breadboard’s center trench, with one header row on each side. Use the labels printed on the Pico and the official Pico pinout; do not count pins from memory.

Pico
GP15 → 1 kΩ
resistor → LED
long → short → Pico
GND
  1. Put the LED legs into different breadboard rows.
  2. Connect the LED’s short leg to a Pico GND pin with a jumper.
  3. Place one end of the 1 kΩ resistor in the same row as the LED’s long leg.
  4. Connect the resistor’s other end to Pico GP15 with a jumper.
  5. Trace the path aloud: “GP15, resistor, long LED leg, short LED leg, ground.”
How do I identify the LED legs?

The long leg is normally the anode (+), toward GP15. The short leg is normally the cathode (−), toward GND. A flat edge on the plastic body often marks the cathode. See the first-wiring reference.

Which way should the resistor face?

Either way. This resistor has no polarity. Its job is to limit current through the LED.

Why 1 kΩ when the tutorial says 50–330 Ω?

The tutorial range is shorthand, not a universal safe range. The answer depends on supply voltage, LED forward voltage, and target current.

With a typical red LED, 1 kΩ estimates about 1.3 mA. It is outside that range but is the cautious value you own. The owned 100 Ω part estimates about 13 mA, above our beginner 2–4 mA target.

Use the interactive calculator to see the calculation.

4. Put the rhythm on the Pico

Reconnect USB. Run this prepared main.py on the Pico.

from picozero import LED

led = LED(15)
led.blink(on_time=0.5, off_time=0.5)

LED(15) means the component is wired to GP15. Saving the script as main.py on the Pico makes it run after power-up.

5. Close the feedback loop

Observe

The LED should stay on for half a second, then off for half a second. One complete cycle takes one second.

If it does not blink

  1. Unplug USB before touching anything.
  2. Turn only the LED around; a reversed LED is the most likely beginner fault.
  3. Check that its legs are not in the same connected breadboard row.
  4. Trace GP15 → resistor → long leg → short leg → GND.
  5. Check that picozero.py exists on the Pico and the script has no import error.

Retrieval challenge

Before editing, predict: what will happen if both 0.5 arguments become 0.1?

  1. Say your prediction aloud.
  2. Open main.py in your MicroPython editor.
  3. Change both values to 0.1 and save.
  4. Compare the physical result with your prediction.
Reveal after testing

The LED completes five cycles each second: 0.1 seconds on plus 0.1 seconds off gives a 0.2-second cycle. You have changed a visible modulation rate—the same idea the final Mod Rate control will perform continuously.

Where this goes

  1. External LED: produce a visible rhythm.
  2. Button: make the LED respond to a press, then become the siren trigger.
  3. Button modes: distinguish momentary, toggle, and selector behaviour.
  4. Potentiometer: turn a 10 kΩ pot to vary blink/modulation rate.
  5. Change LEDs: safely swap standard two-leg LEDs and compare polarity and brightness.
  6. Control panel: read five panel pots through the bought 74HC4051 and read the five-position selector.
  7. USB-MIDI siren: send trigger, pitch, modulation, feedback, and tempo to a Mac synth.
  8. Standalone later: add I²S audio only after the PCM5102A module is purchased and checked.

Done means

  • The external LED blinks with the 1 kΩ resistor installed.
  • You can identify GP15, GND, LED anode, and LED cathode.
  • You changed blink speed and correctly explained why it changed.
  • You unplugged USB before every wiring change.

Tell your teaching agent what happened: “It blinked,” what speed change you observed, or exactly where it failed. Ask any follow-up question—photos of the breadboard are especially useful for wiring checks.
