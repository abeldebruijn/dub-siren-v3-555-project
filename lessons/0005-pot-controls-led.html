Turn light like sound

Use the potentiometer as an amount control and the button as a gate. This is the control pattern your siren will reuse.

15 min · keep Lessons 2 and 4 wired

← Lesson 4 Code Change LED Test Lesson 6 ->
Today’s winHold Trigger and turn the knob: LED brightness follows your hand.

1. Keep all three controls

GP14 → button → GND + 3V3 → pot → GND + wiper → GP26 + GP15 → 1 kΩ → LED → GND

The pot wiring is unchanged from Lesson 4’s diagram.

2. Map input to output

Run this main.py:

from picozero import Button, LED, Pot
from time import sleep

led = LED(15)
button = Button(14)
pot = Pot(26)

while True:
    if button.is_pressed:
        led.value = pot.value
    else:
        led.off()
    sleep(0.01)

led.value accepts the same 0.0…1.0 range produced by pot.value. The Pico rapidly switches the LED to create apparent brightness levels; this is PWM.

3. Play the control

  1. Button released: turn knob; LED stays off.
  2. Hold button: turn knob slowly; brightness changes.
  3. Release: LED turns off immediately.
  4. Hold again: previous knob position determines brightness.
Siren translation

Say which line acts like Trigger, and which value could later become Mod Amount.

4. Change the LED colour

Unplug USB. Remove the red LED only. Insert a yellow or green LED in the same holes and orientation: long leg toward the resistor/GP15 side; short leg toward GND. Keep the 1 kΩ resistor.

Reconnect and repeat the test. Different colours can appear brighter at the same value. Do not use the starter-pack white LED here; its forward voltage is too close to 3.3 V for this beginner circuit.

The replacement LED does not light

Unplug USB and rotate the LED 180°. LEDs conduct in one direction. Then verify the resistor stayed in series rather than being bypassed.

Done means

  • The button gates the LED.
  • The potentiometer changes brightness while held.
  • You safely swapped red for yellow or green.
  • You can connect this pattern to Trigger and Mod Amount.
