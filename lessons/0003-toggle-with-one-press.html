Press once, remember

Change the button from momentary control into a latching control: press once for on, again for off.

10 min · no wiring changes

← Lesson 2 Predict Code Test Lesson 4 ->
Today’s winThe Pico remembers the LED state between presses.

1. Keep the circuit

Keep GP15 → 1 kΩ → LED → GND and GP14 → button → GND. No component moves.

2. Compare two control rules

Retrieve

In Lesson 2, what event turned the LED off? Predict what must change if release should do nothing.

Momentary means the output follows the button. Toggle means every press changes state and release does nothing.

3. Give press one job

Run this main.py:

from picozero import Button, LED

led = LED(15)
button = Button(14)

button.when_pressed = led.toggle

toggle changes off → on or on → off. There is no when_released action.

4. Test its memory

  1. Press and release once: LED stays on.
  2. Wait five seconds: LED remains on.
  3. Press again: LED turns off.
  4. Try a long press. It should still change only once.
It changes twice from one press

The contacts may bounce. Keep Button(14); picozero debounces it. Reseat the button if the behavior continues.

5. Connect it to the siren

The final Trigger is momentary: sound only while held. A power or “hold” control would be latched. Same button; different software rule.

Done means

  • One press turns the LED on; the next turns it off.
  • You can explain momentary versus toggle.
  • You know omitted release code means release has no assigned action.
