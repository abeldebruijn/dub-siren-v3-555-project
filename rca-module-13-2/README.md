# RCA Module 13.2 sound lessons

This is a separate, small lesson track for proving the audio-output chain before it is integrated into the Dub Siren V3 controls.

## Lessons

- [Lesson 1: First tones](lessons/0001-first-tones.html) — power the RCA Module 13.2 from a USB-powered Pico 2 and play three fixed I2S tones.
- [Lesson 2: Continuous prepared tones](lessons/0002-continuous-oscillator.html) — prepare repeating tone blocks before playback and avoid I2S buffer underruns.

## Boundaries for this track

- First prove that the Pico, I2S wiring, PCM5102A DAC, and audio output work together.
- Use a separate Pico and breadboard when that keeps the experiment clear.
- Add one new idea per lesson.
- Leave the five controls, CD74HC4051, modulation, and final integration for later lessons.
