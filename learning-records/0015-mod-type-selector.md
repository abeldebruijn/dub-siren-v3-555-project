# Five-position Mod Type selector

Lesson 15 introduces the purchased Lorlin CK1050. It is a 2-pole, 6-position, break-before-make rotary switch. The learner uses pole A only: common A goes to GND, contacts 1–5 go to GP2–GP6 with internal pull-ups, and contact 6 remains unused. Pole C and contacts 7–12 remain unused.

The diagnostic program prints software values 0–4 for the five physical positions. It ignores the brief no-contact state that occurs while the break-before-make switch turns. GP10–GP12 remain reserved for the future I²S DAC.
