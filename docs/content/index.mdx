# Breadboard language

Breadboard is a small language for describing a breadboard, placing chips, and connecting them with orthogonal wires. The compiler turns the description into a deterministic SVG and reports precise errors and warnings.

## A complete program

This five-row example declares a board, describes a tiny chip, places it, and connects two of its named pins. Change the source and the compiled diagram updates immediately.

## How to read the language

Each statement starts on a new line. Keywords and names are case-insensitive. `//` starts a comment. A typical program is read from top to bottom:

1. Optionally declare the `breadboard` size.
2. Declare reusable `chip` definitions.
3. `place` chip instances on terminal rows.
4. Add `wire` connections.
