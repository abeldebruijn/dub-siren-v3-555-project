# Breadboard language V0.2

Breadboard is a small language for course diagrams. V0.2 describes one board, singleton chips, discrete components, physical controls, wires, and numbered annotations. The compiler returns precise diagnostics, a canonical model, and deterministic SVG. It does not simulate voltage or current.

## Declaration order

Write declarations from top to bottom:

1. Optional `breadboard` declaration.
2. Components: `chip`, `led`, `capacitor`, `resistor`, `button`, `potentiometer`, and `switch`.
3. `wire` declarations.
4. Numbered `annotation` declarations.

A component must be declared before another statement references it. Properties inside a component block may appear in any order and cannot repeat.

Start with [Breadboard](./language/breadboard.mdx), or use the sidebar to learn positions, components, controls, and references.
