# Wires

Wires connect two resolved electrical groups. They only use horizontal and vertical segments.

```text
wire <endpoint> --> <endpoint>
  [via <exact-position> [, <exact-position> ...]]
  [color <colour>]
  [saturation <percentage>]
```

## Automatic routes

Without `via`, the compiler selects endpoints and finds a deterministic orthogonal route with as few unnecessary connections and bends as possible.

## Via points

Every `via` point must be an exact coordinate such as `LT-R1C1` or `RG5`. Via points guide the visible path; they do not create an electrical connection at that intermediate hole.
