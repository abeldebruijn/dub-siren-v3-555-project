# Breadboard

The optional `breadboard` statement controls the board name, row count, and number of terminal columns on each side. It must be the first declaration in a V0.2 document.

```text
breadboard [name] rows <integer> [columns <integer>]
```

## Rows

`rows` is required when the declaration is present. Rows are numbered from top to bottom starting at `1`.

## Columns

`columns` controls the terminal holes on each side of the centre gap. It is optional and defaults to `5`. On the left terminal the visual order is `5 4 3 2 1`; on the right it is `1 2 3 4 5`.

## Omitted declaration

The complete first line may be omitted. The compiler then uses its default board. Writing the declaration is recommended in course examples because dimensions and layout intent remain visible.
