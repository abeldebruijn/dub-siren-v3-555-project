# Complete grammar

This page keeps the complete surface grammar together. Optional items appear in `[brackets]`; repeated items end in `...`; alternatives are separated with `|`. Whitespace separates tokens, newlines separate statements, and `//` comments continue to the end of a line.

## Document

```text
document = newline* statement (newline+ statement)* newline*
statement = breadboard | chip | placement | wire
```

A document is line-oriented. Declarations must appear before references that depend on them.

## Breadboard statement

```text
breadboard = "breadboard" [name] "rows" integer ["columns" integer]
```

See [Breadboard](./breadboard.mdx) for defaults and dimensions.

## Chip definition

```text
chip = "chip" name "{" newline chip-member* "}"
chip-member = height | width | colour | pin
height = "height" integer newline
width = "width" integer newline
colour = "color" colour-value newline
pin = "pin" integer alias ("|" alias)* newline
```

The member order is height, width, colour, then ascending pins. Properties are optional; a chip still needs enough pin information to infer its height.

## Placement

```text
placement = "place" instance chip-name "at" row ["flip"] ["color" colour-value]
row = "R" integer
```

`flip` reverses the physical pin sides without changing the pin numbers.

## Wire

```text
wire = "wire" endpoint "-->" endpoint
       ["via" exact-point ("," exact-point)*]
       ["color" colour-value]
       ["saturation" percentage]
```

The optional clauses appear in the order shown.

## Endpoint

```text
endpoint = rail-selector | terminal-selector | pin-selector
rail-selector = ["L" | "R"] ("P" | "G") [integer]
terminal-selector = ["LT-" | "RT-"] "R" integer "C" [integer]
pin-selector = instance "." (integer | alias)
```

Partial selectors are resolved to available holes. See [Positions and shortcuts](../reference/positions.mdx) for every form.

## Exact route point

```text
exact-point = exact-rail | exact-terminal
exact-rail = ("LP" | "LG" | "RP" | "RG") integer
exact-terminal = ("LT-" | "RT-") "R" integer "C" integer
```

Route points after `via` are exact: side, row, and terminal column cannot be omitted.

## Colour value

```text
colour-value = named-colour | "#" hex hex hex hex hex hex
named-colour = black | red | brown | orange | yellow | green | forest |
               blue | cyan | purple | grey | white
percentage = integer "%"
```

Hex colours contain exactly six hexadecimal digits. Saturation ranges from `0%` to `100%`.

## Names and literals

```text
name = letter-or-underscore (letter | digit | "_" | "-")*
alias = name
integer = digit+
newline = "\\n" | "\\r\\n"
comment = "//" any-character-except-newline*
```

Keywords and names are case-insensitive. Reserved keywords cannot be used as names.
