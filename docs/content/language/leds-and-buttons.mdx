# LEDs and buttons

## LED

```text
led <name> from <anode> to <cathode> {
  [color <colour>]
  [on true | false]
  [display-legs true | false]
}
```

The first endpoint is the anode (`+`) and the second is the cathode (`−`). Colour defaults to red, `on` defaults to false, and `display-legs` defaults to true. Connecting the anode directly to ground or cathode directly to positive produces a warning.

## Button

```text
button <name> {
  [pins-per-side <integer>]
  [on true | false]
} at R<row> [outside]
```

A button straddles the centre gap. `pins-per-side` defaults to `2`. Pins on each side are internally connected; `on true` connects both sides. Named terminals are `left1…leftN` and `right1…rightN`.
