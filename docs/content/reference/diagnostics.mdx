# Errors and warnings

The compiler returns ordered diagnostics with a stable code, severity, source range, and human-readable message.

## Errors

Errors prevent the canonical breadboard model and SVG. Common examples are an unknown component pin, an invalid value, an unavailable endpoint, a duplicate component name, overlap, or board overflow.

## Warnings

Warnings preserve the model and SVG. They identify suspicious but drawable situations such as reversed LED or polarised-capacitor rail polarity, duplicate connectivity, or overlapping wire routes.
